## Gaps this run showed
1. **Status stays `in_progress` at 100%.** Done or review should come from a PR or merge, which needs the GitHub App (M8).
2. **No title without `task_start`.** Codex sessions that don't call MCP get no title. Option: take the title from the branch name (`T-7-multiply` → "multiply").
3. **Small-model wording** ("fixed" for "implemented"), and refusing to answer "nothing is blocked".
4. **Ports:** 8787 is the live ccbridge bridge and 8790 is the neatHack app on this laptop, so the hub ran on a random free port.
