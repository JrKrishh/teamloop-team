Super Agents
How it works

Nobody types a status update.

Super Agents sits on each laptop next to the coding agents you already use. It notices the work as it happens and keeps everyone's board current.

01

Install and sign in

Download the app and continue with GitHub. Create your team, or join with the link your lead sends.

02

Connect your repos

Pick a folder. Super Agents wires Claude Code and Codex hooks into personal files that stay out of git.

03

Code as usual

Each session reports a one-line summary and facts: files changed, tests passed or failed, commits, PRs.

Agent S

Ask anything. Get the evidence.

Agent S runs on NVIDIA Nemotron. It answers only from your team's session events, and every answer points to the events it comes from.

  • "What's blocked?" Blockers, with the sessions that show them.
  • Progress you can trust. "Done" needs a merged PR, passing tests or a commit, not just the agent's word.
  • A daily digest for the lead: shipped, in progress, blocked, at risk.
Agent S
Privacy

Summaries leave the laptop. Code never does.

The summary is written on each laptop. You can pause sharing with one switch, and leads see work, not people: no rankings, no time tracking.

What's shared

  • A one-line summary of each agent turn
  • Facts: files changed, test results, commits, PRs
  • The task you're on and which coding tool

Never shared

  • Your prompts and the agent's replies
  • Tool output, file contents and diffs
  • Keystrokes, screenshots, time tracking
