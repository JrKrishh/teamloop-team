How it works

Nobody types a status update.

Super Agents sits on each laptop next to the coding agents you already use. It notices the work as it happens and keeps everyone's board current.

Agent S

Ask anything. Get the evidence.

Agent S runs on NVIDIA Nemotron. It answers only from your team's session events, and every answer points to the events it comes from.

  • "What's blocked?" Blockers, with the sessions that show them.
  • Progress you can trust. "Done" needs passing tests or a commit, not just the agent's word.
  • A daily digest for the lead: shipped, in progress, blocked, at risk.

Super Team

Ask a teammate's agent for a hand.

Send a part of the work into a teammate's own Claude Code or Codex session. They decide how: off, ask each time or automatic, read only or edit, with a daily limit.

  • Their rules, every time. Nothing runs in someone's session without the access they chose.
  • It waits while they're away. A prompt keeps for 7 days while their laptop is off, and every prompt and answer stays on record.
  • Files and branches hand over. Specs and logs for one teammate or everyone, kept 14 days; code goes as a branch.
Privacy

Summaries leave the laptop. Code stays, unless you share it.

NVIDIA Nemotron writes each summary from the agent's last message, which the server doesn't keep. You can pause sharing with one switch, and leads see work, not people: no rankings, no time tracking.

What's shared

  • A one-line summary of each agent turn
  • Facts: files changed, test results, commits, token counts
  • The task you're on and which coding tool
  • What you choose: files you send a teammate, and prompts teammates send into your sessions, by your rules

Never shared with the team

  • Your prompts and the agent's replies in your coding sessions
  • Tool output, file contents and diffs
  • Keystrokes, screenshots, time tracking

Chats with the app's own agents are answered by NVIDIA Nemotron through the Super Agents server; they aren't stored there.
