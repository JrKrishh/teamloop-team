Mascot art is TeamLoop neatHack's Hoodie mascot (github.com/sourabhnirvani/teamloop, MIT), downscaled to 180x240.
- `agent-s/`: Agent S (black).
- `green/`, `pink/`, `purple/`, `orange/` and `olive/`: team members.
- Poses: `idle` (working), `oops` (blocked), `cheer` (done), `sleep` (away), `think` and `wave`.
